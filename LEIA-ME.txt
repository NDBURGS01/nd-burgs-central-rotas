ND BURGS - CENTRAL DE ROTAS | PACOTE GITHUB PAGES + PWA

ARQUIVOS INCLUÍDOS
- index.html: página de entrada da Central de Rotas.
- config.js: endereço publicado do Google Apps Script (/exec).
- manifest.webmanifest: nome, cores, escopo e ícones para instalação PWA.
- sw.js: Service Worker para cache da página de entrada e arquivos estáticos.
- assets/icon.svg, icon-192.png e icon-512.png: ícones do aplicativo.

PUBLICAÇÃO
1. Extraia todo o conteúdo do ZIP.
2. Envie TODOS os arquivos e a pasta assets para a raiz do repositório:
   https://github.com/NDBURGS01/nd-burgs-central-rotas
3. No GitHub, abra Settings > Pages.
4. Em Build and deployment, escolha Deploy from a branch.
5. Selecione a branch main e a pasta /(root), depois salve.
6. Aguarde a publicação do GitHub Pages.

ENDEREÇO DO SISTEMA
O botão ABRIR SISTEMA aponta para o endereço /exec informado pelo proprietário, configurado em config.js.

IMPORTANTE
- Este pacote publica a página de entrada no GitHub Pages. O sistema principal e seu banco continuam no Google Apps Script.
- O manifest e o Service Worker são para a página hospedada no GitHub Pages; não substituem os arquivos do projeto Apps Script.
- O cache offline guarda apenas a página de entrada e seus arquivos estáticos. O painel principal exige conexão e abre no Google Apps Script.
- Não envie Code.gs, senhas, PINs, tokens, chaves ou dados de clientes para repositório público.
- Se alterar a versão do site, atualize CACHE_NAME em sw.js (por exemplo, nd-burgs-pages-v2) para renovar o cache dos dispositivos.


CORRECAO DE ABERTURA
- O botao ABRIR SISTEMA abre o Apps Script em uma nova aba, sem iframe.
- Se aparecer “script.google.com recusou estabelecer ligacao” dentro de outra pagina, remova qualquer iframe que esteja incorporando o /exec. Use apenas o link direto.
- Se a URL /exec abrir diretamente e mostrar erro de acesso, revise Implantar > Gerenciar implantacoes e confirme acesso permitido para os usuarios pretendidos.
